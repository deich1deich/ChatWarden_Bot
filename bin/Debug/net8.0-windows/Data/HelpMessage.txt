Список команд для пользователей:
1. /roll - Генерирует случайное число от 0 до значения которое вы указали.
Пример: /roll 100 Вывод - 52
2. /voteban - Начинает процесс голосования против участника чата.
Пример: /voteban должен быть ответом на сообщение пользователя.
Примечание: нельзя начинать по отношению к админам, за исключением случаев, когда голосование начинает создатель чата.
3. /vote - Голосование за бан в текущий момент голосования.
4. /profile - Показывает ваш профиль или профиль другого пользователя.
Пример: /profile показывает ваш профиль. /profile [имя_пользователя] - показывает профиль другого пользователя.

Список команд для админов:
1. /editname - Изменяет второй ник пользователя в профиле.
Пример: /editname [новый_ник] должен быть ответом сообщение пользователя чей ник нужно изменить
2. /point - добавляет или отнимает кол-во очков на счету пользователя.
Пример: /point [число] прибавляет введенное кол-во очков. /point [-число] отнимает введенное кол-во очков у пользователя, должно быть ответом на сообщение пользователя чьё кол-во очков нужно изменить.
3. /warn - Добавляет или отнимает предупреждения у пользователя
Пример: /warn [число] добавляет, /warn [-число] убавляет.
4. /badword - Добавляет слово в черный список и после удаляется при появлении в чате.
Пример: /badword [слово]
5. /rank - прибавляет или отнимает введенное значение к рангу.
Пример: /rank 1 прибавит к текущему рангу. /rank -1 отнимит от текущего ранга.
